# 将配置随工程共享

**随工程保存配置**默认勾选。点击 **保存** 或 **保存并配置** 后，正常保存会同步更新所选工作区工程中的 `.vscode/stm32-easy.json`，无需反复导出；不需要共享时取消勾选，配置只保存在本机。

编辑器补全会同时写入 Microsoft C/C++ 的 `C_Cpp.default.compileCommands` 和 clangd 的 `--compile-commands-dir` / `--query-driver`。在 Trae 等 Microsoft C/C++ 被许可证限制、只能使用 clangd 的衍生环境中，安装 clangd 扩展后即可使用补全和诊断；切换 Debug/Release 或编译器时插件会更新参数并重启 clangd。

把 `.vscode/stm32-easy.json` 与源码一起提交到 Git；如果生成了 `.vscode/stm32-easy/openocd/`，也提交其中的脚本。另一台电脑打开工程时会自动读取配置，重新选择该电脑上的编译、烧录工具即可。不会从共享文件安装或自动执行工具。

## 保存的内容

- 相对源码目录、构建方案、Build Preset、构建配置和固件目标名称。
- 芯片型号、OpenOCD 配置脚本与类型、通信方式、SWD 速度，以及调试时是否停在 main。
- 不保存工具安装路径、工具检查结果、工程绝对路径、ELF 路径、探针序列号、芯片确认或已记住的硬件授权。上述本机信息留在插件本地存储中。

Configure Preset、Build Preset 和 CLion Profile 是对既有配置的引用，不复制工具链定义。团队还需提交对应的 CMakePresets、工具链脚本或 CLion 共享 Profile（`.idea/cmake.xml`）。仅存在于某人 `.idea/workspace.xml` 的本地 Profile 不会因保存本文件而自动变成团队 Profile。

## OpenOCD 路径

工程内脚本存为相对工程根目录的路径。OpenOCD 内置脚本保留 `target/stm32f4x.cfg` 等相对于各自 OpenOCD scripts 目录的路径，不记录该工具的安装位置。

工程外的独立脚本会复制到 `.vscode/stm32-easy/openocd/`，原文件不变。文件名包含内容摘要，避免覆盖已有脚本。脚本包含本机绝对路径、非内置的 source 依赖或无法确认的相对依赖时，保存会报错；先把相关脚本整理到工程内并使用可移植的引用，再保存。插件不会复制 OpenOCD 程序和整个工具目录。

复制或更换脚本后，下次硬件操作会弹窗确认芯片、脚本和固件。其他人首次读取共享配置时也需在本机确认，硬件授权不继承；界面无需勾选芯片确认框。

## 同步与冲突

文件监听会刷新页面。Git 切换、手动编辑或另一窗口保存都会改变配置版本；未保存草稿仍保留，旧草稿不能覆盖新文件。点击“放弃修改”后加载新版本。操作执行期间，共享配置发生变化会使旧固件证据失效，阻止继续烧录。

取消勾选后，当前电脑只保存本机配置；已有共享文件保留，避免意外删除团队文件。其他电脑仍可读取它。再次勾选并保存会将当前设置同步到工程文件。

本机和工程配置写入有互斥锁与冲突检查。本机记录写入失败时回滚本次共享文件更新。异常退出后如遗留 `.vscode/stm32-easy.json.lock`，先确认其中记录的 PID 已结束再处理锁文件；该临时文件无需提交 Git。

## 从旧版本迁移

0.5.7 起使用 .vscode/stm32-easy.json。工程根目录中的旧版 .stm32-easy.json 仍可读取；下一次启用共享保存时写入新位置。两个文件同时存在时，以新位置为准。迁移保留旧文件作为备份；确认新文件已提交后可自行移除旧文件。新文件格式有误时会报错，不会静默回退到旧配置。

JSON 内的源码和工程脚本路径仍相对于工作区工程根目录，不相对于 .vscode。已有脚本引用继续有效；新复制的外部脚本放入 .vscode/stm32-easy/openocd/。

## 删除已有配置

进入 **工程设置 → 高级 → 删除已有配置…**，核对弹窗中的工程路径后确认。操作清除当前电脑上该工程的插件设置、共享配置文件（包括根目录旧版文件）及已记住的硬件确认，并放弃当前页面草稿。构建方案、目标缓存和操作结果同步重置。

保留源码、CMake Presets、CLion 配置、VS Code 的 settings.json / launch.json、工具安装与路径，以及 OpenOCD 脚本文件。不会递归删除 .vscode 或脚本目录。插件本机存储保留带新修订号的默认记录，用于阻止旧页面重新写回已删除的设置。其他电脑上的本机配置需要在相应电脑单独清除。

运行中不能删除；弹窗取消不改配置，过期页面不能删除新设置。文件清理或本机持久化失败时恢复本次已删除的配置文件；若硬件授权已撤销，下次硬件操作需重新确认。
