## 验证方法与复现

```text
npm run check
npm test
npm run test:ui
```

Node 测试使用临时文件和模拟后端，不将这些结果当作硬件验收。UI 测试由 `scripts/webview-smoke.cjs` 启动隔离无头 Edge，只访问本机 HTTP 测试页，结果和截图保存于 `.cache/webview-smoke-*`，最新索引为 `.cache/webview-smoke-latest.json`。不会访问用户浏览器配置。

真实工具链测试：

```text
node scripts/real-smoke.cjs <包含 active 工具 JSON 记录的目录>
```

该脚本不下载工具，在 `.cache/release-smoke-*` 新建测试工程，只选取 Arm GNU、CMake、Ninja，禁止到达硬件后端。报告索引为 `.cache/release-smoke-latest.json`。

扩展宿主入口为 `scripts/extension-smoke.cjs`。运行前在 `.cache/extension-smoke-context.json` 指定 version、source、artifact、projects、output，均指向隔离测试工程及存储。通过 VS Code 的 `--extensionDevelopmentPath` 指向从 VSIX 安装的扩展目录，`--extensionTestsPath` 指向此入口，并指定独立 `--user-data-dir` 与 `--extensions-dir`。测试配置不影响日常 VS Code；仅测试工程关闭工作区信任提示。
